01 / 업무 요청 · 1분

다음 달 연체 가능성을 미리 볼 수 있을까요?

고객 리스트 한 장으로 시작합니다. 정답이 있는 과거 사례에서 패턴을 배우고, 새로운 고객에게 적용해 봅니다.

“누구에게 납부 안내를 먼저 해야 할지,
데이터로 판단할 단서를 보여주세요.”

입력

현재 소득, 한도 이용률,
과거 연체 이력 등 5개 항목

정답

다음 달 납부기한을
30일 이상 넘겼는가?

결과

새 고객의 다음 달 연체
확률에 대한 모델 추정치

02 / AI의 분석 계획 · 1분

가설을 세우고, 정답을 가려서 검증합니다.

다음 내용은 공개 가능한 분석 계획과 판단 근거입니다.

검증할 가설

① 과거 연체가 많으면 다음 달 연체도 잦을까?

② 한도 이용률·상환부담률이 높으면 연체가 잦을까?

관찰되는 패턴은 인과관계의 증명이 아닙니다.

시험할 접근

① 전원 정상: 비교를 위한 출발점

② 로지스틱 회귀: 여러 신호를 함께 반영

③ 얕은 결정나무: 단순한 조건으로 분기

180명5개 입력 + 미래 정답
→
144명4묶음 교차검증으로 모델 선택
→
36명선택 후 최종 테스트 1회

180명은 소규모 시연을 위한 규모입니다. 검증 묶음마다 36명, 연체 9–10명을 확보합니다. 안정적인 실무 모델에 필요한 표본 수를 뜻하지 않습니다.

선택 기준은 미리 정한 확률 오차(Brier)의 교차검증 평균입니다. 테스트 정답은 모델 선택에 사용하지 않습니다.
03 / 데이터 확인 · 1–2분

먼저 엑셀을 읽고, 패턴을 확인합니다.

과거 연체 횟수별 다음 달 연체 비율

한도 이용률별 다음 달 연체 비율

그래프는 학습용 144명에서 계산했습니다. 표본 수(n)가 작은 구간은 흔들릴 수 있습니다. 미래 정답은 학습·평가에만 쓰고 예측 입력에 넣지 않습니다.

열의 의미와 데이터 생성 방법

과거 연체: 직전 12개월 30일 이상 연체 횟수. 한도 이용률: 한도 대비 사용액. 상환부담률: 월 상환액 ÷ 월 소득. 거래기간: 서비스 이용 개월 수. 가상 ID는 식별용이며 모델에 넣지 않습니다.

고정 시드 20261007로 입력을 만들고, 과거 연체·이용률 등이 반영된 확률에서 0/1 정답을 추첨했습니다. 가설과 패턴이 데이터 생성 규칙에 들어간 교육용 예시입니다. 누락·중복 ID 없음, 모든 입력 범위 확인.

04 / 기준 모델의 함정 · 1분

모두 “정상”이라고 해도 72%를 맞힙니다.

정상 고객이 더 많기 때문입니다. 정확도 하나로는 업무에 도움이 되는지 알기 어렵습니다.

72.2%테스트 정확도

26명 정상 → 맞힘

10명 연체 → 모두 놓침

연체 발견률 0%

함께 볼 숫자

연체 발견률 · 실제 연체 중 찾아낸 비율

AUC · 연체 고객을 더 높은 순위에 놓는 정도. 0.5는 구분력이 없는 기준

확률 오차 · 예측 확률과 0/1 정답의 제곱 차이 평균. 작을수록 좋음

“대부분 맞혔다”와 “연체 고객을 찾아냈다”는 각각 확인해야 합니다. 여기서 이진 판정은 확률 50% 이상을 연체로 보는 동일한 기준을 사용합니다.
05 / 실제 모델 비교 · 1–2분

확률 오차가 가장 작은 모델을 고릅니다.

학습 내부 4묶음 교차검증 결과로 를 선택했습니다.

교차검증 평균 ± 묶음 간 표준편차. 각 묶음의 정답을 가리고 학습합니다. 표준화도 묶음 내부에서만 계산합니다.

선택한 이유

차이가 작고 검증 편차가 큽니다. 다른 작은 표본에서는 순위가 바뀔 수 있습니다.

선택 후, 처음 보는 36명

정확도

최종 테스트 전체 점수 · 고정된 실험 설정

로지스틱: 표준화 + C=1. 결정나무: 깊이 3, 말단 최소 12명. 시드 고정. 초매개변수·판정 기준을 테스트 점수에 맞춰 바꾸지 않았습니다. 최종 모델은 학습용 144명으로만 학습했습니다.

Brier는 확률 추정의 오차를 비교하지만, 확률 보정이 검증되었다는 뜻은 아닙니다. 작은 가상 표본은 실무 성능의 근거가 될 수 없습니다.

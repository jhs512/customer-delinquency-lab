“누구에게 납부 안내를 먼저 해야 할지,

02 / AI의 분석 계획 · 1분

가설을 세우고, 정답을 가려서 검증합니다.

다음 내용은 공개 가능한 분석 계획과 판단 근거입니다.

검증할 가설

① 같은 연체 2회라도 오래전과 최근 연속 연체가 다를까?

② 월별 기록에서 최근성·연속성을 추가하면 확률 오차가 줄까?

관찰되는 패턴은 인과관계의 증명이 아닙니다.

시험할 접근

① 전원 정상: 비교를 위한 출발점

② 로지스틱 회귀: 횟수만 / 횟수+최근성+연속성 비교

③ 얕은 결정나무: 월별 기록에서 만든 신호로 분기

180명현재 정보 4개 + 과거 월별 기록 6개
→
144명4묶음 교차검증으로 모델 선택
→
36명선택 후 최종 테스트 1회

180명은 소규모 시연을 위한 규모입니다. 검증 묶음마다 36명이며, 이번 자료에는 연체가 5–6명뿐입니다. 안정적인 실무 모델에 필요한 표본 수를 뜻하지 않습니다.

선택 기준은 미리 정한 확률 오차(Brier)의 교차검증 평균입니다. 테스트 정답은 모델 선택에 사용하지 않습니다.
03 / 데이터 확인 · 1–2분

고객 세 명을 쉽게 읽어볼까요?

숫자를 외울 필요 없이, 언제 밀렸는지부터 보세요.

정상은 30일 이상 밀린 기록이 없는 경우, 연체는 납부 날짜를 30일 이상 넘긴 경우입니다.
앞의 여섯 달은 과거 기록이고, 다음 달 결과는 가상 자료에 적힌 정답입니다.

같은 고객을 엑셀 표처럼 보기

6개월 연체 횟수별 다음 달 연체 비율

지난달 연체 여부별 다음 달 연체 비율

그래프는 학습용 144명에서 계산했습니다. 표본 수(n)가 작은 구간은 흔들릴 수 있습니다. 미래 정답은 학습·평가에만 쓰고 예측 입력에 넣지 않습니다.

열의 의미와 데이터 생성 방법

월별 기록: 6개월 전부터 지난달까지 각 월의 납부기한을 30일 이상 넘겼으면 1, 아니면 0. 예측은 그 다음 달을 대상으로 합니다. 한도 이용률: 한도 대비 사용액. 상환부담률: 월 상환액 ÷ 월 소득. 거래기간: 서비스 이용 개월 수. 가상 ID는 식별용이며 모델에 넣지 않습니다.

고정 시드 20261007로 입력을 만들고, 월별 기록을 만든 뒤, 최근·연속 연체와 이용률 등이 반영된 확률에서 다음 달 정답을 추첨했습니다. 최근성·연속성 가설이 생성 규칙에 들어간 교육용 예시입니다. 이번 월별 가상 고객 자료를 새로 생성했으므로 이전 버전 점수와 직접 비교할 수 없습니다. 새 자료 안의 모든 후보는 같은 정답·고객 분리·검증 묶음으로 비교합니다. 누락·중복 ID 없음, 모든 입력 범위 확인.

04 / 기준 모델의 함정 · 1분

정상 고객이 더 많기 때문입니다. 정확도 하나로는 업무에 도움이 되는지 알기 어렵습니다.

테스트 정확도

정상 → 맞힘

연체 → 모두 놓침

연체 발견률 0%

함께 볼 숫자

연체 발견률 · 실제 연체 중 찾아낸 비율

AUC · 연체 고객을 더 높은 순위에 놓는 정도. 0.5는 구분력이 없는 기준

확률 오차 · 예측 확률과 0/1 정답의 제곱 차이 평균. 작을수록 좋음

“대부분 맞혔다”와 “연체 고객을 찾아냈다”는 각각 확인해야 합니다. 여기서 이진 판정은 확률 50% 이상을 연체로 보는 동일한 기준을 사용합니다.
05 / 실제 모델 비교 · 1–2분

확률 오차가 가장 작은 모델을 고릅니다.

학습 내부 4묶음 교차검증 결과로 를 선택했습니다.

확률 오차는 교차검증 평균 ± 묶음 간 표준편차. 나머지는 평균. 각 묶음의 정답을 가리고 학습합니다. 표준화도 묶음 내부에서만 계산합니다.

선택한 이유

차이가 작고 검증 편차가 큽니다. 다른 작은 표본에서는 순위가 바뀔 수 있습니다.

선택 후, 처음 보는 36명

정확도

최종 테스트 전체 점수 · 고정된 실험 설정

로지스틱: 표준화 + C=1. 결정나무: 깊이 3, 말단 최소 12명. 시드 고정. 초매개변수·판정 기준을 테스트 점수에 맞춰 바꾸지 않았습니다. 최종 모델은 학습용 144명으로만 학습했습니다.

Brier는 확률 추정의 오차를 비교하지만, 확률 보정이 검증되었다는 뜻은 아닙니다. 작은 가상 표본은 실무 성능의 근거가 될 수 없습니다. 동일 관측시점의 고객을 분리한 평가이며, 다른 미래 기간에 대한 검증은 아닙니다.
